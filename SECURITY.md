# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository. Do not open a public issue for a security problem.

We aim to acknowledge reports within 72 hours and to provide a remediation
timeline within seven days.

## Scope

In scope: authentication and session handling, authorization and role
enforcement, content mutation paths, injection of any kind, and exposure of
secrets or personal data.

Out of scope: findings that require a compromised maintainer account, denial of
service through unbounded request volume, and reports generated by automated
scanners without a demonstrated exploit path.

## Supported versions

The `main` branch is the only supported version. Fixes ship forward.
